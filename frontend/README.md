# DialogPulse — Frontend

Фронтенд часть проекта DialogPulse. Бэкенд запускается отдельно, инструкция в соответствующем README.

## Требования

- Node.js версии 24 и выше — скачать можно на [nodejs.org](https://nodejs.org)

## Установка и запуск

**1. Перейди в папку фронтенда**

```bash
cd frontend
```

**2. В первый раз установи зависимости**

```bash
npm install
```

**3. Создай файл с переменными окружения**

В папке `frontend` создай файл `.env` и добавь туда:

```
VITE_DIALOG_PULSE_URL=http://127.0.0.1:8000
```

Замени `http://127.0.0.1:8000` на адрес по которому у тебя запущен бэкенд.

**4. Запусти проект**

```bash
npm run dev
```

После этого в терминале появится адрес вида `http://localhost:5173` — открой его в браузере.

## Полезные команды

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск в режиме разработки |
| `npm run build` | Сборка для продакшена |
| `npm run preview` | Предпросмотр продакшен сборки |
| `npm run lint` | Проверка кода линтером |
